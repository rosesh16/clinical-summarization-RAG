# Limitations and safety

This research application is not a medical device and does not diagnose, prescribe, or replace a clinician. OCR can misread characters; its output is marked for review and OCR confidence is never treated as factual proof. Table extraction is conservative and may need manual review for complex PDF layouts. The default named medication matcher is intentionally limited, and clinical terminology/model behavior requires document-specific evaluation. Passing tests does not establish clinical safety or diagnostic reliability.
